# 📡 攤位現場即時展示 (Live Demo)

歡迎您親臨我們的攤位！在這裡，我們將理論付諸實踐，展示一套完整的、即時的地震觀測系統。

除了 `network.md` 頁面中展示的 CWA 專業級觀測網，我們也在攤位上架設了一套「**展示用**」的即時觀測系統，它是由 **Raspberry Shake 1D** 地震儀与 **Raspberry Pi (樹莓派)** 組成。

> **重要說明：** 攤位上的 Raspberry Shake **並非 CWA 目前在役的正式地震儀**，它僅為現場展示「即時地震波形」與「公民地震科學」概念之用。

---

## 什麼是 Raspberry Shake?

Raspberry Shake 是一套廣受歡迎的「公民地震儀」，它將專業級的地震感測器（垂直向 1D 地動儀）與 Raspberry Pi 單板電腦相結合，讓學校、家庭或像我們這樣的專業人士，都能夠以低成本架設自己的地震觀測站，並將資料即時串流至全球地震觀測網。

這呼應了 `network.md` 頁面中提到，CWA 亦投入 Raspberry Pi 於地震儀器上的相關研究。

---

## 您在攤位上能看到什麼？

我們攤位上的螢幕，正**即時顯示**由這台 Raspberry Shake 所偵測到的**本地地震波形**。

![攤位現場展示的 Raspberry Shake 1D 地震儀](./assets/img/live_demo_rshake.jpg)
*圖1：我們在 ACES 攤位現場展示的 Raspberry Shake 1D (安裝於透明外殼中)。這台儀器正即時偵測本地的地動訊號。*

* **即時地動：** 您所看到的波形，就是「現在、此刻」此地的地表震動。
* **跺腳測試：** 歡迎您在攤位旁**用力跺腳**！您會立刻在螢幕上看到波形產生劇烈的變化——這就是您的「人造地震」！

這個展示的目的是讓您親身體驗，地震儀是如何靈敏地捕捉到最微小的地表運動。這也**模擬**了 CWA 遍布全臺的 600 多個**專業測站**，每天 24 小時不間斷在做的工作。
